# 🛒 Sistema de Gestão - Luizão Atacarejo

[![Status](https://img.shields.io/website?url=https%3A%2F%2Fluizaoatacarejo.com.br%2F&label=Status&up_message=Online&style=flat-square)](https://luizaoatacarejo.com.br/)

## 🚀 Destaques do Projeto

Uma solução eficiente para eliminar planilhas manuais e centralizar a operação do mercado.

- ✅ **Organização por Setores:** Navegação intuitiva com páginas específicas (Açougue, Padaria, Frios, etc).
- ✅ **Carrinho via WhatsApp:** Finalização de compra moderna que envia o pedido pronto para o vendedor.
- ✅ **Painel Administrativo:** Área restrita e segura para gestão total de produtos (CRUD).
- ✅ **Preços em Tempo Real:** Banco de dados dinâmico mantendo valores sempre atualizados.
- ✅ **Design Responsivo:** Layout adaptável para celulares e desktops (baseado em SB Admin).

---

## 🛠 Tecnologias Utilizadas

* **Back-end:** [PHP](https://www.php.net/)
* **Front-end:** HTML5, CSS3, JavaScript
* **Banco de Dados:** [MySQL](https://www.mysql.com/)
* **Template:** SB Admin (Bootstrap)

---

## ⚙️ Como Configurar (Instalação)
1.  Clone este repositório.
2.  Copie o arquivo `conexao.example.php` e renomeie para `conexao.php`.
3.  Abra o `conexao.php` e insira suas credenciais do banco (usuário e senha).
4.  Importe o banco de dados (se houver arquivo `.sql`).
5.  Rode em um servidor local (XAMPP/WAMP).

## ⚠️ Nota de Segurança
Arquivos sensíveis como senhas de banco de dados não foram incluídos no repositório. Utilize os arquivos `.example` fornecidos como modelo.
